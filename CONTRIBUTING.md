# Contributing to ForeMetric

We welcome high-quality contributions from serious developers and researchers who understand the importance of the mission: building verifiable human signal infrastructure in the age of Model Collapse.

## Bounty Program

ForeMetric maintains an active bounty program funded from the **Contributors Pool (7,500,000 $FORE)**.

### Rules

- **Human contributors only.** Submissions generated by AI agents or automated tools are automatically rejected.
- **One submission per issue.** Multiple claims on the same bounty will be treated as spam.
- **Quality over speed.** We evaluate code quality, test coverage, architectural alignment, and security.
- **Payment in $FORE only.** All rewards are paid in $FORE at Fair Launch (Q3 2026).
- **Vesting:** 6-month cliff + 12-month linear unlock.

### How to contribute

1. Comment on the issue stating your approach and experience.
2. Wait for explicit acknowledgment from the team before starting work.
3. Submit a clean PR with full test coverage and documentation.
4. Participate in the code review process.

We review all serious applications within 48–72 hours.

### Reward levels (examples)

- Proof-of-Behavior algorithm: 75,000 $FORE
- Signal Passport TEE nullifier: 75,000 $FORE
- Other complex tasks: 30,000–100,000 $FORE (depending on scope)

See open bounties: [Issues with label "bounty"](https://github.com/foremetric/foremetric/issues?q=is%3Aopen+is%3Aissue+label%3Abounty)
