# Contributing to ForeMetric

ForeMetric is infrastructure for the consented collection and monetization of behavioral data. We welcome serious developers and researchers who care about getting privacy, security and honest status reporting right.

At this stage ForeMetric is a small founding team working on a pre-launch product, and development happens in private repositories. This public repository is the project's front page: it does not take code contributions.

---

## Ways to Help

| Way | What it means |
|---|---|
| **Try the prototype** | Use the public prototype at [foremetric.ai](https://foremetric.ai) (simulated data) and tell us what is unclear or broken |
| **Join the waitlist** | Closed alpha waitlist: https://luma.com/bxt0dn3t. The alpha is invite-only and has not started |
| **Report security issues** | Responsible disclosure only, see [SECURITY.md](SECURITY.md) |
| **Review the design** | Questions or objections about the consent model, the trust model or the token specification are welcome by email |
| **Reach out directly** | Researchers and engineers: **info@foremetric.ai**, subject line "Contribution" |

### What We Value

- **Clarity feedback.** If something on the website or in the prototype is confusing, that is genuinely useful signal.
- **Quality over speed.** We care about correctness, privacy and security.
- **Honesty about status.** The project separates what runs today from what is only designed (see Status in the [README](README.md)). Feedback that keeps this distinction sharp is welcome.

### How to Reach Us

1. Read the [README](README.md) for the current project status and design.
2. For general questions and ideas, write to **info@foremetric.ai**.
3. For security reports, follow [SECURITY.md](SECURITY.md). Please do not report security issues publicly.

We aim to reply within **72 hours**.

---

## Issues and Pull Requests

This repository does not take code contributions. Unsolicited pull requests are closed without review, and so are automated or AI-generated submissions. Please do not open issues about bounties, rewards or support requests; write to info@foremetric.ai instead.

---

## No Bounty Program

There is no bounty program. The bounty listings that used to be in this repository were discontinued and closed. We do not currently offer tokens, rewards, vesting or token allocations for contributions, and no token is deployed. If someone offers you $HSIG or any "ForeMetric tokens" in exchange for work, it is not from us.
