# Contributing to ForeMetric

ForeMetric is built by a small founding team, and development happens in private repositories. This public repository does not take code contributions.

## Ways to help

- **Try the prototype** at [foremetric.ai](https://foremetric.ai) and tell us what is unclear.
- **Join the closed alpha waitlist:** https://luma.com/bxt0dn3t
- **Report a security issue** privately: see [SECURITY.md](SECURITY.md).
- **Researchers and engineers:** write to info@foremetric.ai with the subject "Contribution".

## Issues and pull requests

Unsolicited pull requests are closed without review, and so are automated or AI-generated submissions. We aim to answer email within 72 hours.

## Bounties and tokens

There is no bounty program. The bounty listings that used to be in this repository were discontinued and closed. We do not currently offer tokens or token allocations for contributions, and no token is deployed. If someone offers you ForeMetric tokens for work, it is not from us.
