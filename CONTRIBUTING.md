
# Contributing to ForeMetric

**ForeMetric is built by a small founding team. Development happens in private repositories, and this public repository does not take code contributions.**

Contact: **info@foremetric.ai** | Closed alpha waitlist: https://luma.com/bxt0dn3t

> **No bounty program. No tokens for contributions.** No token is deployed today. The ways that actually help are listed below.

## Ways to help

| Way | What it means |
|---|---|
| **Try the prototype** | Use the public prototype at [foremetric.ai](https://foremetric.ai) and tell us what is unclear |
| **Join the closed alpha waitlist** | Register at https://luma.com/bxt0dn3t |
| **Report a security issue** | Privately, by email — see [SECURITY.md](SECURITY.md). Please do not open a public issue for a vulnerability |
| **Reach out directly** | Researchers and engineers: **info@foremetric.ai**, subject line "Contribution" |

## Issues and pull requests

Unsolicited pull requests are closed without review, and so are automated or AI-generated submissions. We aim to answer email within 72 hours.

## Bounties and tokens

There is no bounty program. The bounty listings that used to be in this repository were **discontinued and closed**.

We do not offer tokens, rewards, vesting or any token allocation for contributions, and **no token is deployed**. 
If someone offers you $HSIG or any "ForeMetric tokens" in exchange for work, it is not from us.



Thank you for helping build the infrastructure that returns control of behavioral data back to the people who generate it.
