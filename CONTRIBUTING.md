# Contributing to ForeMetric

We welcome serious developers and researchers who understand the importance of the mission: building Human Signal Intelligence infrastructure in the age of Model Collapse.

At this stage ForeMetric is a small founding team working on a pre-launch protocol, and development happens in private repositories. This public repository holds project documentation only, so there is no code to contribute to here.

---

## Ways to Help

| Way | What it means |
|---|---|
| **Try the prototype** | Use the public prototype at [foremetric.ai](https://foremetric.ai) and tell us what is unclear |
| **Report security issues** | Responsible disclosure only — see [SECURITY.md](SECURITY.md) |
| **Reach out directly** | Researchers and engineers: **info@foremetric.ai**, subject line "Contribution" |

### What We Value

- **Clarity feedback.** If something in the whitepaper or the prototype is confusing, that is genuinely useful signal.
- **Quality over speed.** We care about correctness, privacy and security alignment with the protocol design.
- **Honesty about status.** The project publicly separates what runs today from what is only designed. Contributions that keep this distinction sharp are welcome.

### How to Reach Us

1. Read the [README](README.md) for the current project status and design.
2. For general questions, write to **info@foremetric.ai**.
3. For security reports, follow [SECURITY.md](SECURITY.md) — please do not report security issues publicly.

We aim to reply within **48–72 hours**.

---

## No Bounty Program

ForeMetric does not run a bounty program, and we do not offer tokens, rewards, vesting or any token allocation for contributions. No token exists or is deployed today. If someone offers you $HSIG or any "ForeMetric tokens" in exchange for work, it is not from us.
